# 🏥 MedCare — Appointment Booking App

A full-stack healthcare web application for booking and managing patient appointments, deployed live on Railway.

## 🔗 Live Demo
> Add your Railway deployed link here

## 📌 Features
- 8-page full-stack web application
- Supports 50+ patient records
- Full CRUD operations across patient and appointment data
- Complete MySQL database schema designed from scratch
- End-to-end API integration between frontend and backend
- Demoed at college level

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Backend:** Node.js, REST APIs
- **Database:** MySQL
- **Deployment:** Railway
